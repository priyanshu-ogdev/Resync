# `examples/`

Example configurations for downstream projects adopting Resync.

- `resync.toml` — a minimal starting configuration. Copy it to a project's repo root and adjust; see
  `docs/architecture.md#resynctoml-the-compatibility-contract` for the full field reference, and the project's
  own root `resync.toml` for a more fully-populated example including pins, exceptions, and a policy entry.
