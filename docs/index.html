The Fundamental Dilemma

Why Modern Codebases Break

Software development is constrained by two asymmetric failure modes that traditional linters and automated PR bots cannot prevent.

1. Old Code Rots (Dependency Drift)

Upstream libraries deprecate and remove public APIs between versions. Codebases quietly accumulate call sites targeting obsolete signatures that fail immediately upon upgrade, causing cascading regressions.

19% – 35% of breaking changes pass test suites silently

2. New Code Hallucinates (AI Slopsquatting)

AI coding agents hallucinate non-existent packages and obsolete signatures. Attackers pre-register these hallucinated names on registries with malicious payloads, creating immediate supply-chain vulnerabilities.

4.6% – 19.7% AI agent package hallucination rate (USENIX '25)
